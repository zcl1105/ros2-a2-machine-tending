# 八页 PPT 草案与五人分工

此文件是内容草案，不是已经生成的 PPTX。运行后补入真实截图、数据和姓名。建议 PPT 6 分钟、视频 2–3 分钟、问答 3 分钟。

| 页 | 标题 | 内容与材料 |
| --- | --- | --- |
| 1 | A2 模拟机床上下料 | 小组与成员、Ubuntu 22.04 / ROS 2 Humble、场景截图 |
| 2 | 工业任务与成功标准 | 输入毛坯，取料→上料→加工→下料→返回；初始与最终截图 |
| 3 | 系统架构与 ROS 接口 | 四节点图、Action / Service / Topic、节点列表截图 |
| 4 | 机械臂与工位执行 | SCARA 逆解、关节插值、抬升转移、夹爪；工位状态与互锁 |
| 5 | 自行开发逻辑 | 状态机、执行结果确认、取消、超时、日志；代码片段与文件名 |
| 6 | 完整任务演示 | 播放实际视频，突出连续闭环和最终结果 |
| 7 | 测试与分析 | 五场景、CI / Ubuntu 日志、真实耗时、失败原因与复位 |
| 8 | 分工、来源与改进 | 每人贡献、ROS/RViz 等复用组件、自主部分、仓库与启动方式 |

PPT 注明仓库链接、提交号和 README 启动说明位置，不将 ROS 框架、RViz、robot_state_publisher 记为自主开发成果。

| 角色 | 工作 | 可展示成果 |
| --- | --- | --- |
| A 仿真与平台 | URDF、RViz、launch、环境 | 模型与 TF、场景启动 |
| B 动作与执行 | arm_node、运动学 | 单次动作、夹爪、取消与反馈 |
| C 感知与交互 | machine_node、工位信号 | 占用 / 在位 / 完成、互锁与故障注入 |
| D 任务与记录 | task_node、任务模型 | 完整状态机、异常与 CSV / JSON |
| E 集成与测试 | 可视化、验收、CI、结果整理 | 五种测试、视频与 PPT |

C 对应课程允许的“工位信号处理”，当前不含相机识别。按实际工作修改分工，所有人参与 Ubuntu 联调与汇报。工具辅助生成的代码需要本人理解、运行和解释，准确说明辅助工具与实际贡献。

| 周 | 任务 | 检查点 |
| --- | --- | --- |
| 1 | 环境、选题、场景、接口 | 一页选题说明 + 运行截图 |
| 2 | 各模块实现 | 单次动作、取放与加工信号 |
| 3 | 全流程、异常、日志 | 完整任务试录视频 |
| 4 | 重复测试、结果、汇报 | PPT + 2–3 分钟视频 + 源码启动说明 |

问答重点：Action / Service / Topic 的选择；退出工位再加工的互锁；动作失败为何不会继续；运动学仿真与动力学 / 碰撞规划的差别；占用 / 超时 / 取消如何复位；扩展后端哪些部分可复用。
