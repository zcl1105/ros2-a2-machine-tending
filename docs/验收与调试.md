# Ubuntu 验收与调试

## 验收顺序

```bash
cd ~/a2_ws
source /opt/ros/humble/setup.bash
bash scripts/build.sh
source install/setup.bash
bash scripts/integration.sh
```

集成脚本自动启动五组真实 ROS 进程，无需另开 demo。每组使用不同域（默认 72–76），通过服务、Action 和话题判断结果，不会操作默认域中的录屏。可用 `A2_TEST_DOMAIN_ID=82 bash scripts/integration.sh` 修改。成功输出每组 `PASS`；失败打印 launch 日志并返回非零退出码。

| 场景 | 条件 | 预期 |
| --- | --- | --- |
| 正常 | 正常加工 | COMPLETE、成品回料盘、归位、完成数 1 |
| 占用后恢复 | 初始 BUSY 4 秒 | WAIT_READY 后完成 |
| 加工超时 | stall=true，超时 3 秒 | FAILED、WAIT_PROCESS timeout、完成数 0 |
| 工位等待超时 | 占用 30 秒，超时 2 秒 | FAILED、WAIT_READY timeout、完成数 0 |
| 取消 | TRANSFER_LOAD 阶段 cancel | CANCELED、动作停止、完成数 0 |

每组还检查重复启动和运行中复位被拒绝、终止后能复位到 IDLE。正常场景检查关键阶段、工件标记、夹爪打开与归位。JSON / CSV / launch 日志保存在 `results/integration/`。

## 现场检查

```bash
ros2 launch a2_demo demo.launch.py
```

另一个已 source 的终端：

```bash
ros2 node list
ros2 action list -t
ros2 service list -t
ros2 topic hz /a2/arm/state
ros2 topic echo /a2/task/status
```

主要应用节点应有 `/arm_sim`、`/machine_sim`、`/task_manager`、`/scene_view`；动作应有 `/a2/arm/move`。成功后 `phase=COMPLETE`、`success=true`、`completed=1`；工件 `location=TRAY`、`processed=true`；机械臂 `busy=false`、夹爪打开，TCP 接近 `(0.50, 0.0, 0.56)`。启动服务返回 success 只代表接受，不代表完成。

## 记录

每次运行产生唯一编号和同名 CSV / JSON。CSV 列为经过秒数、阶段、事件、工件位置、加工标记、说明；进入阶段与终止时即时刷新。JSON 为最终成功标记、完成数、耗时、工件位置、加工标记、异常和后端说明。取消 / 失败不能计为完成。强制杀进程或断电可能只有部分 CSV，不保证得到终止 JSON。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| Package not found | 在 workspace 根目录构建，当前终端 source install/setup.bash |
| 找不到自定义接口 | 查看 CMake 构建日志，完整 colcon build，不只复制 Python |
| 服务无响应 | 检查节点、两个终端 ROS_DOMAIN_ID；测试使用隔离域 |
| 无机器人 | RViz Fixed Frame=world；Description Topic=/robot_description；Durability=Transient Local；检查 TF |
| 无场景 / HUD | MarkerArray 订阅 /a2/scene；检查 scene_view |
| 画面卡顿 | 检查虚拟机 3D 加速；先 rviz:=false 验证逻辑 |
| 正常也加工超时 | process_timeout > process_seconds，且 stall=false |
| 复位拒绝 | 先取消，等待机械臂和未完成请求停止，再复位 |
| 复位后仍超时 | stall 为启动参数，以 stall:=false 重新启动 |
| 未出现 BUSY | 占用从工位启动计时，改用 BUSY_ON / BUSY_OFF 服务 |
| START 被拒绝 | 检查工件在位、夹爪打开、机械臂退出、状态新鲜度 |

当前是运动学仿真，没有接触力学和规划器碰撞检测，不可据此声称完成动力学 / 真机安全验证。报告问题时附上 Ubuntu 版本、ROS_DISTRO、提交号、启动命令、JSON / CSV / launch 日志。
