# 结课交付检查清单

本项目依据截图中的 A2 最低任务和课程视频要求实现。说明文档中的参考软件与参考机械臂是示例，最低要求没有明确指定 Gazebo、MoveIt 或某一型号。

| 课程要求 | 当前交付内容 |
| --- | --- |
| 工业任务清楚 | 毛坯和启动指令输入，取料、上料、加工、下料、回料盘，验证成品和归位 |
| 至少两个 ROS 功能节点 | 四个应用节点，独立 Action / Service / Message 接口包 |
| 自行开发核心逻辑 | 21 阶段任务状态机、执行结果确认、工位互锁、异常和记录 |
| A2 完成一次上下料循环 | ROS 云端正常验收成功，真实 CSV / JSON 记录已纳入 examples |
| 展示各阶段状态 | TaskStatus、MachineState、ArmState、RViz HUD 与进度 |
| 从启动到结束可复现 | README、launch、Ubuntu 构建和五场景验收脚本 |
| 保存结果 / 运行记录 | CSV、JSON、可选 rosbag、CI artifacts |
| 一次条件变化 / 失败处理 | 占用恢复、工位等待超时、加工超时、取消和复位均有验收 |
| 2–3 分钟视频 | 自动录制真实 ROS / RViz，正常完整流程与加工超时 / 复位，字幕说明与 1× 标记 |
| PPT 6–8 页 | 已提供八页内容草案，最终 PPTX 仍需生成，并填写真实组员与贡献 |
| 来源与自主部分 | README 和汇报草案注明 ROS / RViz / robot_state_publisher 来源与自写代码 |
| 五人共同联调与个人成果 | 已有分工建议，实际成员贡献须由小组补充，不可代填 |

最终提交前，请在你们使用的 Ubuntu 桌面环境运行一次，确认教学设备的图形驱动与显示效果；补齐真实组员姓名、个人成果和 PPTX。当前仿真后端是运动学仿真，不能声称完成动力学接触、真实机床或真机安全验证。
